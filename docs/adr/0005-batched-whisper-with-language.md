# ADR-0005: Whisper는 직접 일괄 호출하고 감지 언어를 함께 돌려준다

- 상태: 채택
- 결정일: 2026-10-21
- 기록: 2026-10-22 소급 작성

## 맥락
- 수천 개 클립을 받아써야 했다. 한 개씩 하면 클립당 약 1.5초가 걸린다.
- 감지 언어(한국인 발음을 Whisper가 ko로 판단하는지)가 분석의 핵심이었다.
- transformers 파이프라인은 일괄 처리와 `return_language`를 함께 쓰면 오류가 났다.
- 최신 transformers의 `generate`는 출력에서 언어 토큰을 떼어 낸다.

## 결정
- `WhisperProcessor`와 `generate`로 8개씩 묶어 처리한다.
- 언어를 지정하지 않으면 `detect_language`(generate가 쓰는 것과 같은 판정)로 먼저 감지한다. 그 언어를 `generate`에 넘기고, 결과에 ISO 코드로 함께 돌려준다.
- 단건 `transcribe`도 같은 경로를 쓴다(결과 형식 통일).

## 결과
- 클립당 약 0.3초가 걸린다. 언어 감지를 위해 인코더를 한 번 더 돌리므로 약 30% 느려진다.
- 30초가 넘는 음성은 잘린다(Whisper 창 길이).
